# 情绪之道项目上下文

## 产品定位

情绪之道是一个面向个人投资者的 C 端投研操作系统。它不做交易执行，不承诺收益，也不输出确定性买卖建议；它帮助用户把每天的事件、产业链传导、市场情绪、板块轮动、热门概念、个股线索、新闻证据和个人判断沉淀成可复盘的研究流程。

它的核心观点是：

> 持续追踪投资逻辑，而不是追逐股价。

## 核心目标

- 捕捉：自动整理不同来源的新闻、公告、财报、电话会议和行情异动。
- 连接：梳理事件会影响哪些行业、产业链节点、上下游和相关公司。
- 判断：区分真正受益、短期情绪、市场已定价和潜在预期差。
- 记录：保存用户自己的观察、假设、关注理由、证据和待验证问题。
- 复盘：几周或几个月后回看当初为什么关注，以及判断是否需要修正。
- 生成：把数据、证据和个人判断整理成日报、主题报告、个股观察和复盘记录。

## 非目标

- 不提供证券投资顾问意义上的确定买卖建议。
- 不接入真实下单、券商交易、资金账户或自动交易。
- 不把未经授权的行情数据公开转发或商业分发。
- 不把 AI 输出视为事实本身；关键结论必须能追溯数据来源或用户输入。

## 个人用户工作流

```text
打开首页
-> 看今日事件、市场状态和关注对象
-> 点选一个主题、事件、板块或公司
-> 查看它影响的行业与产业链路径
-> 识别相关公司是真受益还是情绪交易
-> 阅读 AI 辅助整理的证据和风险
-> 保存自己的研究判断和待验证问题
-> 后续复盘判断是否有效
```

## 产品原则

- 数据先行：先呈现资金、涨跌、量比、人气、新闻，再生成解释。
- 结论可追溯：每段 AI 结论都要能对应到输入数据或用户笔记。
- 面向复盘：平台价值不是一次性判断，而是让用户长期积累自己的市场记忆。
- 情绪克制：界面应该清爽、克制、可扫读，避免制造追涨焦虑。
- 本地优先：早期优先本机运行和个人使用，后续再考虑账号、同步和云端部署。
- 研究优先：价格和资金是研究入口，不是研究终点。
