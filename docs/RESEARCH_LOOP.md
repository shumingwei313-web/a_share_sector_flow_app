# 个人研究闭环

## 起源叙事

真正优秀的研究者，并不是每天盯着价格变化。他们更关心：

- 今天发生了什么？
- 它会影响哪些行业？
- 上下游之间是怎样传导的？
- 哪些企业真正受益？
- 哪些只是市场情绪？
- 当初为什么会得出这个判断？

情绪之道要解决的不是“帮用户买什么”，而是帮助用户完成重复、耗时、容易遗忘的信息整理工作。

## 研究闭环

```text
1. Capture 捕捉
   事件、新闻、公告、财报、电话会议、研报观点、行情异动。

2. Connect 连接
   把事件连接到行业、产业链节点、上下游、公司和市场预期，明确产业链传导路径。

3. Compare 比较
   比较基本面影响、市场反应、资金流向和已有预期。

4. Conclude 形成判断
   生成可追溯的研究假设，而不是买卖指令。

5. Commit 记录
   保存当时的观察、证据、疑问、置信度和风险。

6. Check 复盘
   未来回看结果，判断哪些想法正确，哪些假设需要修正。
```

## 核心对象

```text
Event: 发生了什么
Industry: 影响哪个行业
SupplyChainNode: 产业链节点
Company: 哪些公司相关
Evidence: 证据来源
Hypothesis: 研究假设
ExpectationGap: 预期差
DecisionNote: 个人观察
Review: 复盘结果
```

## 每日工作台

每日工作台应该回答 5 个问题：

1. 今天有哪些重要事件？
2. 这些事件影响哪些行业和产业链？
3. 哪些公司可能受益或受损？
4. 市场是否已经反应，还是存在预期差？
5. 我今天应该记录或复盘什么？

## AI 的职责

AI 应该做：

- 多来源信息聚合。
- 公告、财报、电话会议和研报摘要。
- 产业链关系整理。
- 事件影响路径推理。
- 研究笔记结构化。
- 历史判断检索和复盘提醒。

AI 不应该做：

- 替用户直接决策。
- 输出确定买卖建议。
- 隐藏证据来源。
- 把市场情绪伪装成基本面事实。
