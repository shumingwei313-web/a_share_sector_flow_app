# Investment OS 追踪与借鉴

## 公开可见信号

`investmentos.cn` 的公开页面内容较少，但从页面截图和可见结构可以提炼出它的产品方向：

- 它不是传统行情软件，而是研究操作系统。
- 首页主标题强调“持续追踪投资逻辑，而不是追逐股价”。
- 搜索入口支持公司、代码、指数、主题或事件。
- 左侧导航覆盖：总览、瓶颈雷达、研究工作台、研究主题、产业图谱、事件推理、预期差、因果验证、研究日报。
- 首页不是单纯行情列表，而是把市场、关注标的、晨间简报、研究信号放在同一个研究入口。
- 文案强调把世界事件、产业链、公司利润和预期差串成可验证的研究链。

## 它真正优秀的地方

优秀点不在于界面暗色或卡片样式，而在于它把投资研究抽象成连续系统：

```text
事件
-> 影响行业
-> 产业链传导
-> 公司受益或受损
-> 市场预期是否充分
-> 证据是否支持
-> 形成研究记录
-> 未来复盘验证
```

这条链路比“今天涨了什么”更接近优秀研究者的日常工作。

## 对情绪之道的启发

当前情绪之道偏重行情与资金情绪。下一阶段应该把中心从“价格和资金”转向“研究链路”。

需要从：

```text
板块资金看板
```

升级为：

```text
个人研究工作台
```

核心变化：

- 价格只是入口，研究逻辑才是主体。
- 热点不是结论，热点背后的产业链传导才是研究对象。
- AI 不替用户决策，只替用户收集、整理、归档和提醒。
- 最重要的资产不是 AI 总结，而是用户自己的判断过程。

## 可以借鉴的模块

| Investment OS 信号 | 情绪之道对应模块 | 第一阶段落地方式 |
| --- | --- | --- |
| 搜索公司、主题、事件 | Research Shell | 顶部搜索统一入口 |
| 瓶颈雷达 | 事件与瓶颈雷达 | 跟踪影响产业链的关键事件 |
| 研究工作台 | 今日研究台 | 市场、关注、简报、待办 |
| 研究主题 | 主题库 | AI、机器人、先进制程、低空经济等 |
| 产业图谱 | 产业链图谱 | 上游、中游、下游、相关公司 |
| 事件推理 | 事件影响分析 | 新闻事件 -> 行业 -> 公司 |
| 预期差 | 预期差雷达 | 市场定价 vs 公开信息 |
| 因果验证 | 复盘验证 | 记录判断，未来自动回看 |
| 研究日报 | 日报生成器 | 每天生成个人研究简报 |

## 不应该照搬的部分

- 不做机构级复杂权限和团队协同，先服务个人。
- 不一开始追求覆盖所有市场，先把 A 股和少量美股关注标的做好。
- 不把 AI 结果包装成确定性判断，保留“研究辅助”定位。
- 不让页面变成信息瀑布，要给用户一条明确的研究路径。

## 产品判断

情绪之道的差异化方向应该是：

> 面向个人投资者的可复盘研究助手。它每天帮用户整理公开信息、识别产业链传导、沉淀研究过程，让用户知道自己当初为什么关注一家公司，而不是只记得价格涨跌。
